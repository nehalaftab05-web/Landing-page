 About The Project

Replicating a major production UI like Netflix is a great way to test attention to detail and layout architecture. This project recreates the Netflix login screen entirely from scratch. 

Why it stands out:
Instead of using generic form fields, this clone implements **CSS-only floating labels**. The placeholder text shrinks and transitions smoothly to the top of the input field when focused or populated—exactly mimicking the behavior of the real Netflix application without needing bloated JavaScript event listeners.

Features

* **Pure CSS Floating Labels:** Utilizes the `:not(:placeholder-shown)` pseudo-class and sibling selectors for smooth, JavaScript-free form animations.
* **Responsive Design:** Mobile-first media queries strip away the background imagery on smaller screens to match Netflix's exact mobile browser experience.
* **Modern Layouts:** Built utilizing CSS Flexbox and CSS Grid for structured, predictable component alignment.
* **Interactive UI:** Includes hover states, focus states, and a simulated JavaScript login handler to prevent page reloads and validate interactivity.
* **Zero Dependencies:** 100% Vanilla HTML, CSS, and JavaScript. No Bootstrap, no Tailwind, no React.
